How does ZIP fusion work?

Snapchat sometimes sends media as ZIPs containing:

Main image/video
(main.jpg or main.mp4)
Transparent PNG overlay
with text, stickers, filters
This program automatically merges these elements to get complete media.

What this program does automatically

  • ✓ Automatically detects main/overlay pairs
  • ✓ Merges overlay onto main media
  • ✓ Preserves metadata (date, location)
  • ✓ Moves merged media to main folder

Default Storage Folder

This folder is automatically created when the application starts to store all media downloaded from Snapchat.

Expired Snapchat Links

What happened?

Download was automatically stopped because 10 consecutive files could not be downloaded.

The links provided by Snapchat are probably dead or expired.

Why do links expire?

Snapchat links usually expire after 4 days for security reasons. If you download your data but only import it after this period, the links will be invalid.
