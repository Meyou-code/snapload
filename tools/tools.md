# Tools

This project relies on **ffmpeg** and **exiftool**.

To simplify development and ensure a consistent environment, the required binaries are **already provided** in the `tools/` directory. Developers do **not** need to install these tools system-wide.

---

## 📁 `tools/` Directory

```
tools/
├─ ffmpeg
└─ exiftool
```

When these files are present, the application automatically uses them.

If you wish to use **newer versions** of the tools, you can simply replace the folder in the `tools/` directory with updated official builds.
